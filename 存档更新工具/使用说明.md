# 存档更新工具 · 使用说明

> 位置：`存档更新工具/存档更新工具.bat`（双击即用）、`存档更新工具/存档更新工具.mjs`（工具本体）

## 一、它是干什么的

把**旧规则**的存档更新成**新规则**，缩小体积，用于**防止玩家存档太大导致游戏读不动**（浏览器 IndexedDB 读取失败 / 卡在启动页）。

一份典型的老存档可能有 **8 GB**，更新后会小到 **几十 MB**，且内容不丢（旅人、世界、剧情、聊天正文全在）。

## 二、什么时候该用它

- 存档文件夹特别大（几百 MB ~ 几 GB）
- 游戏打开后**卡在启动页**、或读档失败
- 从旧版本迁移过来的存档

## 三、用它之前（重要）

1. **先关闭游戏**（关掉游戏标签页 / 停掉开发服务）
2. **先备份 `save` 文件夹**（复制一份到别处）
3. 电脑需要装了 **Node.js**（本项目开发环境自带）

## 四、怎么用

**最简单：直接双击 `存档更新工具.bat`。**

它默认是【**预演**】：只告诉你"将会做什么"，**不改任何文件**。

看预演没问题后，再真正执行：

```
node 存档更新工具.mjs --执行
```

给别的存档目录用（例如另一份副本）：

```
node 存档更新工具.mjs "D:\某处\save" --执行
```

## 五、它会改什么

| 项 | 旧规则 | 新规则 |
|---|---|---|
| 剧情编织 | 每条存档都塞**完整原著正文** | 只留**持久化投影**（正文从内置预设水合） |
| 聊天消息 | 带 调试 / 思维链 / 计费 等字段 | **只留正文** |
| 自动存档 | 每回合一份全量，能堆到几百个 | 收敛为「**最新 6 + 根节点**」 |
| 手动存档 / 分支 | —— | **保留**（只是照常瘦身） |

## 六、预演输出怎么看

```
saves 文件：216 个，合计 8512.2MB
自动链长度：180（保留最新 6 + 根节点 = 7，将删除链上旧节点 173；不在链上的节点保留）
```

- **将删除链上旧节点** = 会被清掉的**过期自动存档点**（同一条自动链上更早的）
- **不在链上的节点保留** = **手动存档 / 其它分支不会被删**
- 已经是新规则的存档 → 会显示"将删除链上旧节点 **0**"（安全、幂等）

## 七、出问题怎么办

| 现象 | 处理 |
|---|---|
| 提示"找不到存档目录" | 用参数指定 save 目录：`node 存档更新工具.mjs "路径"` |
| 提示"这不像一个存档目录" | 确认路径里应有 `store/saves`、`manifest.json` |
| 执行后游戏读不到 | 用你备份的 `save` **覆盖回来** |
| 不确定 | **只跑预演**（不加 `--执行`），它绝不改文件 |

> 记住：**预演永远安全**，只有加了 `--执行` 才会写盘；写盘会删除过期自动存档点，**不可逆**，所以务必先备份。

## 八、额外能力：清理「其它自动树」

旧版本在同步时可能**分叉出多余的自动存档树**（同一段故事存了好几棵，白白占空间）。
加参数可一并清理（**只有整棵树全是自动档才删**，含手动/导入的树一律保留）：

```
node 存档更新工具.mjs --清理其它树 --执行
```

（新版已修掉这个分叉问题，不会再产生；此开关用于清理存量。）
