开拓轶事 · 本地运行说明
========================================

【一键启动】
双击「启动游戏.bat」。
- 若提示未检测到 Node.js，请先安装 Node.js 20 LTS 或更高版本：https://nodejs.org/
- 首次启动会自动安装依赖（需要联网，可能几分钟）。
- 之后每次双击即可直接开玩。

【开始游戏】
浏览器会自动打开 http://localhost:3000 。
若没有自动打开，请手动在浏览器地址栏输入该地址。
进入游戏后，打开「设置」，填入你自己的模型 API（Base URL / API Key / 模型名），即可开始游玩。

【存档与数据】
游玩进度与 API 配置会自动保存在本目录下的 save\ 文件夹中（纯本地，不会上传到任何地方）。
清理浏览器缓存不会丢档；清空缓存后重新双击本脚本启动，即可自动从 save\ 恢复。

【停止服务】
关闭标题为「KaiTuoYiShi Server」的命令行窗口即可停止。

【常见问题】
- 端口 3000 被占用：先关闭占用该端口的程序，或重启电脑后再试。
- 依赖安装失败：检查网络后，重新双击脚本。
- 想换一份存档：整个 save\ 文件夹复制走即可，别的机器放回同位置即可继续。
